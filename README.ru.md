# spbstu-mcp

[English](README.md) · **Русский**

https://github.com/user-attachments/assets/79137c69-5d3f-4270-9164-e509f88c3535

MCP-сервер для студентов СПбПУ (Политеха): даёт Claude (и любому другому MCP-клиенту) доступ к твоей учёбе.

| Сервис | Что умеет |
|---|---|
| **dl.spbstu.ru**, **dl-hum.spbstu.ru**, **lms.spbstu.ru**, **dl-phmath.spbstu.ru** (Moodle) | курсы, содержимое курса, задания с полным текстом, дедлайны, тесты (сроки, попытки), преподаватели, уведомления, личные сообщения, поиск по курсам, статус сдачи и оценки, форумы, страницы, файлы; **сдача работ**, посты в форумы и сообщения преподавателям |
| **mail.spbstu.ru** (почта) | список и поиск писем, чтение, сохранение вложений, новые письма и ответы, папки, перенос, отметка «прочитано», календарь, удаление в «Удалённые» |
| **openedu.ru** (Открытое образование) | курсы, прогресс и оценки, сроки, оглавление курса, тесты и экзамены с таймером (старт, вопросы, ответы, завершение) |
| **ruz.spbstu.ru** (расписание) | расписание любой группы или преподавателя на неделю |
| **my.spbstu.ru** («Мой Политех») | зачётка с оценками и средним баллом по семестрам, академические долги, учебный план, рабочий план на год |
| **polyvsp.ru, polyphis.ru** (базы ответов) | поиск ответов на вопросы тестов со ссылкой на источник |

`study_overview` одним вызовом собирает сводку по семестру: дедлайны со всех Moodle-площадок, прогресс на openedu.ru и непрочитанную почту.
`study_subject` — всё по одному предмету (часы, курс на dl, задания, тесты, преподаватели, оценки), `my_debts` — академические долги,
`study_export_ics` — все сроки файлом для Apple, Google или Outlook Календаря.

Тест на openedu.ru по ссылке: каждый вопрос ищется в базах ответов, ответы сохраняются без отправки, а в отчёте каждый вопрос помечен —
✅ из базы, 🟡 из базы, но есть сомнения (ответ базы всё равно ставится), ⚠️ в базе нет, ответ стоит проверить.

Неофициальный проект, к СПбПУ отношения не имеет.

## Установка

Работает на macOS, Linux и Windows: логин и пароль хранятся в системном хранилище учётных данных.

### 1. Логин и пароль ЕУЗ — в хранилище учётных данных

**macOS** (связка ключей), в приложении «Терминал»:

```sh
security add-generic-password -s spbstu -a ЛОГИН@edu.spbstu.ru -T /usr/bin/security -w
```

`ЛОГИН` — логин единой учётной записи (как в почте `ЛОГИН@edu.spbstu.ru`). `-w` должен стоять **последним** — тогда `security` спросит пароль со скрытым вводом. Проверить, что пароль записался (выводит только длину):

```sh
security find-generic-password -s spbstu -w | tr -d '\n' | wc -c
```

**Linux** (GNOME Keyring / KWallet; нужен `secret-tool` из пакета `libsecret-tools` или `libsecret`):

```sh
secret-tool store --label=spbstu service spbstu account ЛОГИН@edu.spbstu.ru
```

**Windows** («Диспетчер учётных данных»):

```powershell
cmdkey /generic:spbstu /user:ЛОГИН@edu.spbstu.ru /pass
```

Пароль везде спрашивается со скрытым вводом и никуда, кроме серверов СПбПУ и openedu.ru, не уходит и в ответах модели не появляется.

### 2. Сервер

Через [Homebrew](https://brew.sh) (macOS, Linux):

```sh
brew install kad-xyz/tap/spbstu-mcp
```

Или вручную. Готовый бинарник — со страницы [Releases](../../releases) для своей системы (`darwin_arm64` — Apple Silicon, `darwin_amd64` — Intel Mac, `linux_*`, `windows_*`). На macOS:

```sh
tar -xzf spbstu-mcp_*_darwin_arm64.tar.gz
xattr -d com.apple.quarantine spbstu-mcp   # бинарник не подписан
mkdir -p ~/.local/bin && mv spbstu-mcp ~/.local/bin/
```

Или поставить из исходников (Go 1.26+): `go install github.com/kad-xyz/spbstu-mcp/cmd/spbstu-mcp@latest`.

### 3. Подключить к Claude

Claude Code:

```sh
claude mcp add spbstu -s user -- "$(command -v spbstu-mcp)"
```

Claude Desktop — в `claude_desktop_config.json` (macOS: `~/Library/Application Support/Claude/`, Windows: `%APPDATA%\Claude\`):

```json
{ "mcpServers": { "spbstu": { "command": "/Users/ИМЯ/.local/bin/spbstu-mcp" } } }
```

Дальше просто спрашивай: «что у меня горит по учёбе», «разбери задание по базам данных», «какие письма пришли от преподавателей».

## Несколько аккаунтов

Сервер может хранить несколько учётных записей, например твою и однокурсника, которому помогаешь, и работает под одной
из них — **активной**. Скажи «добавь аккаунт ivanov.ii»: на macOS откроется системное окно для пароля (вставь его из
приложения «Пароли»), пароль сразу уходит в связку ключей, мимо чата, и один вход проверяет, что он верный. Потом —
«переключись на ivanov.ii», а когда закончишь, обратно.

- Каждый ответ начинается со строки `Аккаунт: ЛОГИН@edu.spbstu.ru` — под кем он получен.
- У каждого аккаунта свои сессии: вход одного человека никогда не используется для другого.
- Всё, что что-то меняет (отправка писем, сдача работ, форумы, ответы на тесты), требует параметр `account` и отказывает,
  если это не активный аккаунт: письмо не уйдёт из почты однокурсника, если забыл переключиться обратно.
- Активный аккаунт запоминается и после перезапуска.

| Инструмент | |
|---|---|
| `account_list` | аккаунты и какой из них активный |
| `account_switch` | сделать активным другой аккаунт |
| `account_add` | добавить аккаунт: пароль вводится в системном окне (macOS) и проверяется одним входом |
| `account_remove` | удалить неактивный аккаунт: его пароль и сохранённые сессии |

На Linux и Windows `account_add` выдаёт команду `secret-tool` или `cmdkey`, которая сохраняет пароль; выполни её и вызови
`account_add` ещё раз. Все аккаунты хранятся под одним именем `spbstu`, по записи на аккаунт (в Windows дополнительный
аккаунт — запись `spbstu:ЛОГИН@edu.spbstu.ru`).

## Как это работает

- **Moodle-площадки СПбПУ** — вход через ЕУЗ (cas.spbstu.ru), затем отдельный для каждой площадки токен мобильного API Moodle, как у приложения Moodle. У всех `dl_*`-инструментов есть необязательный параметр `site` (по умолчанию `dl.spbstu.ru`); для связанных вызовов передавай `site` из результата вместе с идентификатором курса или активности.
- **openedu.ru** — вход через «Политех» в SSO Открытого образования, данные из API Open edX.
- **Почта** — Exchange Web Services с логином и паролем ЕУЗ.
- Сессии хранятся в `~/.config/spbstu-mcp/accounts/ЛОГИН@edu.spbstu.ru/state.json`, у каждого аккаунта свои (доступ только у тебя), поэтому сервер входит заново, только когда сессия истекла: частые входы сайты Политеха блокируют.

## Безопасность

- Всё, что что-то отправляет (`dl_submit_assignment`, `dl_forum_*`, `mail_send`), по описанию инструмента выполняется только после явного подтверждения пользователя; `mail_send` по умолчанию лишь сохраняет черновик.
- Пишущие инструменты отказывают, если параметр `account` не совпадает с активным аккаунтом (см. [Несколько аккаунтов](#несколько-аккаунтов)).
- Экзамены с таймером и прокторингом открываются только в браузере. Ответы на тесты только сохраняются, отправляешь их ты сам.

## Параметры

| Флаг | По умолчанию | |
|---|---|---|
| `-keychain-service` | `spbstu` | имя записей в хранилище учётных данных (по записи на аккаунт) |
| `-downloads` | `~/Downloads/spbstu` | куда сохраняются файлы |
| `-group` | | группа по умолчанию для `schedule`, например `5130902/30201` |
| `-demo` | `false` | выдуманные данные вместо сервисов Политеха, учётка не нужна — попробовать сервер или записать демо |

